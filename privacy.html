Lesson Logger Privacy Policy

Last updated: August 2026

Lesson Logger is designed with privacy in mind and gives users control over where their data is stored.

Data Collection

Lesson Logger does not collect, transmit, sell, or share personal information with the developer.

The app does not require user accounts, registration, subscriptions, advertising identifiers, or analytics tracking.

Data Storage

Data entered into Lesson Logger is stored within a JSON file selected or created by the user. The user chooses where this file is stored.

Depending on the device and services available, the Lesson Logger JSON file may be stored:

  • Locally on the user's own device;
  • Within the user's own iCloud Drive storage;
  • Within the user's own Google Drive storage; or
  • Within another file storage location made available through the device's file system.

Lesson Logger accesses only the file location selected by the user. The app does not automatically upload user data to servers operated by the developer.

Where a user chooses to store their Lesson Logger file using a third-party cloud storage provider such as Apple iCloud Drive or Google Drive, that file is stored and synchronised by the user's chosen storage provider and is subject to that provider's own privacy policy and terms.

File Access

Lesson Logger may request permission to access a file or storage location selected by the user. This access is used solely to read and write the Lesson Logger JSON file and related user-requested data.

The developer does not receive a copy of the user's Lesson Logger file.

Calendar Access

If granted permission, Lesson Logger may access the device calendar solely to create calendar events requested by the user. Calendar data is never collected, transmitted, or stored by the developer.

Third-Party Services

Lesson Logger does not use third-party advertising, analytics, or tracking services.

If the user chooses to store their Lesson Logger file using a third-party cloud storage service, such as iCloud Drive or Google Drive, Lesson Logger interacts with that storage only through the access provided by the user's device and operating system.

Your Data

Users retain complete ownership and control of their Lesson Logger data.

Because the data is stored in a user-controlled JSON file, users may move, copy, back up, export, or delete that file at any time using their device or chosen storage provider.

Data Deletion

Lesson Logger does not maintain a separate developer-controlled copy of user data. To remove Lesson Logger data, the user may delete individual records within the app or delete the Lesson Logger JSON file from the storage location they selected.
