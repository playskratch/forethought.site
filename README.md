# ForeThought website redesign

This package contains the redesigned ForeThought website and the integrated Guided Programmes storefront.

## Upload

Upload every file and folder in this directory to the public web root for `forethought.site`, preserving the `programmes` folder.

The main pages are:

- `index.html`
- `features.html`
- `lesson-logger.html`
- `availability.html`
- `yardagebook.html`
- `programmes/index.html`

The website is completely static. It does not require a build step, package manager, database or server-side runtime.

Existing externally hosted ForeThought screenshots remain linked from the original pages. The Guided Programmes purchase and download controls remain inactive until the final Stripe links and JSON files are connected.
